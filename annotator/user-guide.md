# 用户使用说明（**MyZ 高亮助理**）

本文档面向终端用户，介绍 **MyZ 高亮助理** 的核心功能与 Dashboard 设置项的使用方法。

> 重要提示（网络功能）
>
> - 扩展不提供任何远程服务。所有可选网络请求均由你的浏览器直接发送到你配置的第三方服务（例如 S3 兼容对象存储）。
> - 加密同步为端到端加密（E2EE）：云端仅存储密文与必要元信息，同步密钥只保存在本地设备。
> - 请谨慎处理隐私数据与敏感信息。

## 1. 安装与入口

- 安装后建议把扩展固定在浏览器工具栏，便于快速打开。
- **Popup**：点击浏览器工具栏上的扩展图标打开，适合快速查看当前页面标注与操作入口。
- **Dashboard（设置与管理）**：在 Popup 右上角点击“打开 Dashboard”按钮进入（也可在扩展管理页打开“选项/Options”）。

## 2. 基础标注（高亮 / 下划线 / 波浪线）

1. 在网页中用鼠标选中一段文本。
2. 选区附近会出现浮动工具条：
   - “添加标注”：创建可回放的高亮类标注（可选颜色与样式）。
   - “保存文字”：把选中文本保存为纯文本收藏（不在页面上生成高亮 DOM）。
   - “截取选区截图”：截图并保存（会在截图前暂时清除系统选中态以避免截图带蓝色高亮）。
3. 保存后，扩展图标角标会显示当前页面标注数量（用于快速确认是否已采集）。

## 3. 管理与整理（Popup / Dashboard）

### 3.1 Popup：快速查看当前页面

- 展示当前页面的标注/收藏列表，支持快速定位、编辑与删除等操作。
- 右上角按钮可打开 Dashboard。

### 3.2 Dashboard：全局管理与设置

Dashboard 顶部导航包含以下区域：

- **高亮列表**：展示所有标注，支持卡片 / 列表两种视图（记忆上次选择）、标签多选、全文搜索、日期范围与网站筛选，并采用懒加载保障性能。
- **高亮查看器**：点击任意高亮进入 `/highlights/:id` 查看器，支持同页标注连续阅读、滚动到底自动切换、上一页/下一页导航。
- **设置**：包含高亮偏好、外观、导入与加密同步四个区域（详见第 4 节）。

## 4. Dashboard 设置项

### 4.1 高亮偏好

- **视图模式**：高亮列表默认使用卡片或列表视图。
- **调色板**：选择标注使用的 5 色调色板，可自定义颜色值。
- **默认样式 / 默认颜色**：设置新标注默认使用的样式（高亮 / 下划线 / 波浪线）与颜色。

### 4.2 外观

- **主题**：跟随系统 / 亮色 / 暗色三种模式。

### 4.3 导入标注

- 支持导入 **MyZ JSON**、**RainDrop CSV**、**Weava CSV**、**Chrome 书签 HTML** 文件。
- 导入时可选择冲突处理策略：**跳过重复 / 覆盖重复 / 保留最近更新**，完成后会显示导入摘要。

### 4.4 加密同步（E2EE）

加密同步使用你自己的 S3 兼容对象存储；我们不提供任何线上服务。云端仅存储密文与必要的元信息，密钥始终保存在本地设备中。同步密钥由你输入的密码派生，我们不保存你的密码。

推荐的对象存储：**AWS S3**、**Cloudflare R2**，或其他国内 **S3 兼容**对象存储服务。

配置步骤：

1. 进入 Dashboard → 设置 → **加密同步**。
2. 填写 S3 配置：
   - **Endpoint**：对象存储的 S3 兼容接口地址
   - **Region / Bucket**
   - **Access Key ID / Secret Access Key**
   - **Session Token（可选）**
   - **Prefix（可选）**：用于隔离不同设备/项目的前缀
3. 点击 **保存设置**，然后 **测试连接**。
4. 设置 **同步密钥**：仅保存在本地，建议使用高强度口令。
5. 开启 **启用同步**，并点击 **立即同步** 执行一次手动同步。

同步状态区域会显示 KeyId、Manifest 版本、上次同步时间与密钥更新时间，便于确认同步是否生效。

::: warning 重要提示
同步密钥不可找回。若遗失密码，新的客户端将无法解密旧数据，需要重新全量加密并同步；旧密文无法解密。
:::

::: tip 端到端加密公开审阅
加密同步实现可公开审阅，代码位于 <https://github.com/myz-suite/sync/>。
:::

## 5. PDF 阅读与标注

**打开 PDF**

- 在 Popup 点击 PDF 图标：若当前标签是网页 PDF，会直接在阅读器中打开；否则进入阅读器首页，可选择「打开本地 PDF」。
- 在网页中右键任意 PDF 链接，选择「在 MyZ 中打开 PDF」。
- 本地 PDF 通过文件选择器打开（仅 Chrome，依赖 File System Access API）。

**阅读**

- 默认连续滚动，支持缩放（50%–300%），并自动记忆阅读进度，下次打开回到上次位置。
- 支持 JPEG2000 / JBIG2 等扫描/图片型 PDF。

**标注**

- 用鼠标选中 PDF 文本 → 出现浮动工具条：`高亮` / `保存文字` / `取消`。
- 右侧 Inspector 可修改样式（高亮 / 下划线 / 波浪线）、颜色、批注与标签；点击「保存」写入（失焦也会自动保存）。
- 新建标注默认沿用上次使用的样式与颜色。

**还原与回跳**

- 重新打开同一 PDF 会自动还原高亮：网页 PDF 按 URL 匹配，本地 PDF 按文件指纹匹配（换设备时打开同一文件即可还原）。
- Dashboard 卡片 / 列表 / 查看器会显示「第 N 页」，点击「在阅读器中打开」可跳回阅读器对应页。

> 说明：本地 PDF 目前仅支持 Chrome。

## 6. 禅定模式（Zen Mode）

在包含文章主体的页面，右键菜单可看到：

- “禅定模式 (仅显示文章)”：进入后仅保留文章主体区域的可读内容（不破坏 DOM 结构，尽量避免影响标注恢复）
- “保存文章为图片”：仅在禅定模式启用后可见，用于导出文章主体截图

若菜单未出现，说明当前页面未检测到可识别的文章主体，可等待页面加载完成后重试，或在后续版本中补充规则。

## 7. 常见问题排查

- 高亮无法定位？页面结构变化可能导致高亮暂时无法恢复，此时可在 Popup 或 Dashboard 中将该标注降级为纯文本保存，避免内容丢失。
- 标注与已有高亮重叠？扩展会即时提示并拒绝创建，避免相互嵌套导致定位错乱。
- SPA 页面导航后标注不刷新？扩展监听 History API 与 URL 变更自动恢复，若仍异常请重新加载扩展后重试。
